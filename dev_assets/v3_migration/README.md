# V3 geliştirme arşivi

Bu klasör runtime asset tanımlarına dahil değildir.

- `before/`: V3 öncesi çalışan görseller, kullanıcının düzelttiği altı PNG dahil.
- `source/`: ZIP içeriği, orijinal/şeffaf masterlar ve V3_MANIFEST.json.
- `decisions.json`: 51 adayın kabul/ret nedenleri, boyutu, alfa ve SHA-256 değeri.
- `transparent_comparison.json`: V3 masterlar ile eski çalışan dosyaların birebir karşılaştırması.
- `code_before_hashes.json`: geçiş öncesi kaynak kod SHA-256 değerleri.
- `review_*.png`: inceleme panoları; kaynak sanat değiştirilmedi.
- `browser_*.mjs` ve `web_*.png`: gerçek Chrome etkileşimleri ve görsel kayıtlar.

Tam rapor: `../../ASSET_MIGRATION_V3.md`.
